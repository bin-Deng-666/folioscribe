FolioScribe 标注人工修正说明

以下界面使用仓库自带的合成文档。启动演示后可以安全体验编辑、保存和跨页操作。

我们标注的是版面元素（block）：在页面上它是一组坐标（bbox），在数据里它是一条带类型、内容和证据引用的记录。 标注工具在右侧卡片里改字段，改动以补丁形式存在 annotations/<sample>/page_XXXX.json，不会改动 runs/ 里的模型结果。

〇、5 步上手

  1. 看：切到「标注」模式 → 点页面上一个框，右侧卡片出现。
  2. 判类型：卡片里点类型按钮（或按 1–9）；类型不对先改类型。
  3. 填内容：文本类核对/抄写「框内参考文本」→「复制参考文本到该框」；表格直接改单元格。
  4. 补关系：标题给层级；图表题选所属；跨页选「承接上页 / 不接」；顺序不对用连线核对。
  5. 看进度：卡片底部字段完整度到 n/n 再翻页（Q/E）；自动保存，不用手动存。

不知道从哪下手时：先修类型，再修内容，最后修关系。画布上的框和右侧列表是同一批 block，改任意一边都会同步。

一、要标哪些类型

text正文文本
bbox框位置：贴合文字块边缘（画布坐标自动换算 PDF 坐标，不用手填）
text框内文字：与页面逐字一致；可先「复制参考文本到该框」再核对
cross_page_text跨页：被页边切断时选「承接上页」，确认不接就选「不接」
最常见类型；不要把两行合并成一个框，也不要一框套多段
title标题
bbox框位置：贴合标题行（含编号）
text标题文字：与页面一致
level层级 L1–L6：按视觉大小/编号推断；导出时合同上限为 L4
层级给错会让整份文档的大纲错位，宁可 CHECK 也别乱给
table表格
bbox框位置：包住整张表（含表头；续表只框本页那部分）
html表格结构：含 <table> 且至少一个单元格有内容；用网格直接改单元格
cross_page_table跨页：续表选「承接上页」；k/n 与截断判据由规则给出（只读）
表格以 HTML 为准；跨页续表要写承接关系，不要拆成两张独立表
table_caption表题
bbox框位置：表题文字行
text表题文字：与页面一致
parent_id所属：必须指向它标注的那张表（table）
表题必须挂在表上，否则导出时无法归属
image_caption图题
bbox框位置：图题文字行
text图题文字：与页面一致
parent_id所属：指向对应的图（image）或图表（chart）
图题与图题、图题与正文重复时，保留语义正确的那一个
image图片
bbox框位置：包住整张图（含边框阴影）
没有文本字段；表内图片显示为裁剪缩略图
chart图表
bbox框位置：包住整个图表（坐标轴、图例、数据标签）
数据图/曲线图用 chart；照片、示意图用 image
seal印章
bbox框位置：包住印章本身（红色的章）
章压住文字时，文字与章各自成框
formula公式
bbox框位置：贴合公式区域
text公式文本：可用 LaTeX 记法，按页面视觉抄录
行内公式与行间公式分开框
header页眉
bbox框位置：页面顶部页眉行
text页眉文字：与页面一致，不要与本页正文混淆
页眉/页脚/页码是家具类，逐页重复出现
footer页脚
bbox框位置：页面底部页脚行
text页脚文字：与页面一致
含版权行、期刊信息等；不要与脚注混为一类
page_number页码
bbox框位置：只框页码本身
text页码文本：按页面显示（如 12 / 第 12 页）
页码单独成框，不要与页眉页脚合并
footnote脚注
bbox框位置：页面底部的脚注块
text脚注文字：与页面一致（含注号）
脚注与页脚的区别：脚注有注号、跟随正文引用

判定顺序：先看它是什么（类型），再看它写了什么（text/HTML），最后确认它和别的东西的关系（parent_id、跨页、阅读顺序）。类型选错比内容错更严重。

二、跨页怎么标（text 与 table 用同一套判断）

跨页不是 true/false：文本的“续接”本身就是那条链接，表格的几何判据由规则给出、只读展示。人只需要做三选一里的两个动作：

衔接 · 承接上页

进入拾取模式并自动翻到上一页，点一下被承接的块/表；回来写入 continues_block_id，状态 人工判定。 下一页对应的块会自动写反向链接。

衔接 · 不接

明确判定“本页独立”。写入 continues_block_id: null + status: PASS（null 也是一个结论），并清掉上一页的反向链接。

不动它 = 未定

保持模型/规则给出的值（标 模型判定），导出时可被过滤。

画布上怎么看

跨页段落 紫色虚线外框 + 续表 k/n 琥珀色虚线外框与角标， 浏览模式和标注模式都会显示。

五、质量标准（提交前自己过一遍）

  1. 类型对不对：正文 / 标题 / 表格 / 图 / 图题 / 页眉页脚 / 页码 / 脚注。
  2. 标题层级合理：L1 是文档标题，往下逐级；跳级需要有理由。
  3. 表格至少有一个非空单元格；行数、列数与版面对得上。
  4. caption 指向正确：图题指图、表题指表。
  5. 本页字段完整度（卡片底部进度条）到 n/n；不完整的块会以 chip 列出原因。
  6. 跨页块要么「承接上页」，要么「不接」；不确定就保持模型判定。
  7. 画布上没有重叠框（重叠的框会被校验判为不一致），阅读顺序连线不交叉打结。

标注结果会按 ocr-agent 自己的校验器复核：块级 schema（类型/必填字段/坐标）与 revision 级一致性（证据归属、重叠、阅读顺序）。 校验结果在「标注」页签里显示；有 error 时请修正后再翻页。
